# SAF MultiCopy

แอป Android สำหรับก๊อปปี้โฟลเดอร์จำนวนมากแบบขนาน (หลายไฟล์พร้อมกัน) ใช้ Storage Access Framework (SAF)
จึงใช้ได้กับ **Internal storage, SD card และ USB OTG** โดยไม่ต้อง root
แนวคิดเดียวกับ Robocopy GUI บน Windows

## ดาวน์โหลด / ติดตั้ง

ทุกครั้งที่ push ขึ้น `main` GitHub Actions จะ build APK ให้อัตโนมัติ

1. เปิดหน้านี้บนมือถือ: **[Releases → latest](../../releases/tag/latest)**
2. แตะ `SAF-MultiCopy.apk` เพื่อดาวน์โหลด
3. เปิดไฟล์แล้วติดตั้ง (ครั้งแรกต้องอนุญาต "ติดตั้งแอปที่ไม่รู้จัก" ให้เบราว์เซอร์หรือแอปจัดการไฟล์)

เวอร์ชันใหม่ติดตั้งทับของเดิมได้เลย เพราะ build ทุกครั้งเซ็นด้วยคีย์เดียวกัน (`app/debug.keystore`)

## วิธีใช้

1. **Add source folder** — เพิ่มโฟลเดอร์ต้นทาง (เพิ่มได้หลายโฟลเดอร์)
2. **Choose destination** — เลือกปลายทาง แต่ละต้นทางจะถูกก๊อปไปเป็นโฟลเดอร์ย่อยของตัวเอง
3. กด **Preview** เพื่อดูว่าจะก๊อป/ลบอะไรบ้างโดยยังไม่ทำจริง
4. กด **Start copy**

ก๊อปต่อได้แม้ปิดหน้าจอหรือสลับไปใช้แอปอื่น (ทำงานเป็น foreground service พร้อม wake lock)
และมีตัวเลือก **Keep screen on** ให้หน้าจอไม่ดับระหว่างก๊อป

## ตัวเลือก

| ตัวเลือก | ความหมาย |
|---|---|
| Parallel copies | จำนวนไฟล์ที่ก๊อปพร้อมกัน ไฟล์เล็กจำนวนมาก: 8–16 · แฟลชไดรฟ์/SD card ช้า: 4–8 |
| Mirror | ลบไฟล์ในปลายทางที่ไม่มีในต้นทาง (มีกล่องยืนยันก่อน) |
| Retries | จำนวนครั้งที่ลองใหม่เมื่อก๊อปไม่สำเร็จ |
| Exclude | ข้ามไฟล์/โฟลเดอร์ตามชื่อ คั่นด้วย `;` ใช้ `*` และ `?` ได้ เช่น `*.tmp; Thumbs.db` |

## การตัดสินว่าไฟล์ "เหมือนเดิม"

SAF ตั้งค่าเวลาแก้ไข (last modified) ของไฟล์ปลายทางไม่ได้ ไฟล์ที่ก๊อปแล้วจึงมีเวลาเป็นเวลาที่ก๊อป
แอปจะถือว่าไฟล์ **ไม่เปลี่ยน** เมื่อขนาดเท่ากันและไฟล์ต้นทางไม่ได้ถูกแก้ไขหลังจากที่ก๊อปไปแล้ว
ไฟล์ที่เปลี่ยนจะถูกลบแล้วก๊อปใหม่

## ทำไมถึงเร็ว

- อ่านรายชื่อไฟล์ทั้งโฟลเดอร์ด้วย query เดียว (ไม่ใช้ `DocumentFile.findFile()` ทีละไฟล์)
- เทียบไฟล์ต้นทาง/ปลายทางใน memory ครั้งเดียว
- ก๊อปหลายไฟล์พร้อมกันด้วย coroutines และ buffer 256 KB

## Build เอง

เปิดโฟลเดอร์นี้ใน Android Studio แล้วกด Run หรือใช้คำสั่ง

```bash
./gradlew assembleRelease
```

ไฟล์ log ของแต่ละงานเก็บไว้ใน `Android/data/com.titipong.safmulticopy/files/logs/` และกด Share จากในแอปได้
