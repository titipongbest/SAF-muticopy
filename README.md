# SAF MultiCopy

**by NorthXbar**

แอป Android สำหรับก๊อปปี้โฟลเดอร์จำนวนมากแบบขนาน (หลายไฟล์พร้อมกัน) ใช้ Storage Access Framework (SAF)
จึงใช้ได้กับ **Internal storage, SD card และ USB OTG** โดยไม่ต้อง root
แนวคิดเดียวกับ Robocopy GUI บน Windows

## ดาวน์โหลด / ติดตั้ง

ทุกครั้งที่ push ขึ้น `main` GitHub Actions จะ build APK ให้อัตโนมัติ

1. เปิดหน้านี้บนมือถือ: **[Releases → latest](../../releases/tag/latest)**
2. แตะ `SAF-MultiCopy.apk` เพื่อดาวน์โหลด
3. เปิดไฟล์แล้วติดตั้ง (ครั้งแรกต้องอนุญาต "ติดตั้งแอปที่ไม่รู้จัก" ให้เบราว์เซอร์หรือแอปจัดการไฟล์)

เวอร์ชันใหม่ติดตั้งทับของเดิมได้เลย เพราะทุก build เซ็นด้วย release key เดียวกัน

## Folder pairs (แท็บแรก)

Folder pair คือการจับคู่ "ต้นทาง → ปลายทาง" ที่บันทึกไว้ใช้ซ้ำ แต่ละคู่มีตัวเลือกของตัวเอง (Mirror, Exclude)

1. กด **New folder pair** → เลือกโฟลเดอร์ต้นทางและปลายทาง ตั้งชื่อ (หรือปล่อยว่างให้ตั้งให้อัตโนมัติ) แล้วกด Save
2. ติ๊กคู่ที่ต้องการ แล้วกด **Sync selected** — แอปจะ sync **ทีละคู่ตามลำดับในรายการ** จนครบ
   (แต่ละคู่ยังก๊อปหลายไฟล์พร้อมกันตามค่า Parallel copies)
3. หรือกดปุ่ม **Sync** บนการ์ดเพื่อ sync คู่เดียว

- เนื้อหาของต้นทางจะถูก sync **เข้าไปในโฟลเดอร์ปลายทางโดยตรง** (ไม่สร้างโฟลเดอร์ย่อยเพิ่ม)
- ถ้าคู่ไหนล้มเหลว (เช่น ถอดแฟลชไดรฟ์) จะบันทึกผลไว้แล้วไปทำคู่ถัดไป · กด Stop เพื่อหยุดทั้งคิว
- **แตะการ์ดของคู่ไหน** จะเปิดหน้ารายละเอียดของคู่นั้น: ความคืบหน้าขณะ sync, หลอดวิ่ง และ **Recent files ของคู่นั้นเท่านั้น** (เก็บไว้จาก sync ครั้งล่าสุด ปิดแอปแล้วก็ยังดูได้) พร้อมปุ่ม Edit / Preview / Sync
- การ์ดแต่ละคู่แสดงผลการ sync ล่าสุด เช่น `✓ 12 min ago · copied 120 · unchanged 3,400`
- เปลี่ยนลำดับได้ด้วยปุ่มลูกศรขึ้น/ลงในหน้าแก้ไขคู่ · กด Edit ในหน้ารายละเอียดเพื่อแก้ไขหรือลบ (ลบแค่คู่ ไม่ลบไฟล์)

## Quick copy (แท็บที่สอง)

1. เพิ่มสิ่งที่จะก๊อป (ผสมกันได้)
   - **+ Folder** — เพิ่มโฟลเดอร์ (ได้หลายโฟลเดอร์) แต่ละโฟลเดอร์จะถูกก๊อปไปเป็นโฟลเดอร์ย่อยของตัวเองที่ปลายทาง
   - **+ Files** — เลือกไฟล์ได้หลายไฟล์พร้อมกัน (กดค้างที่ไฟล์แรกแล้วแตะไฟล์อื่นเพิ่ม) ไฟล์จะถูกก๊อปไปไว้ตรงโฟลเดอร์ปลายทาง
     เลือกได้สูงสุด 400 ไฟล์ (Android 10 ลงไป 100 ไฟล์) เพราะ Android จำกัดจำนวนสิทธิ์ที่แอปเก็บไว้ได้ ถ้ามากกว่านั้นให้เพิ่มเป็นโฟลเดอร์แทน
2. **Choose destination** — เลือกโฟลเดอร์ปลายทาง
3. กด **Preview** เพื่อดูว่าจะก๊อป/ลบอะไรบ้างโดยยังไม่ทำจริง
4. กด **Start copy**

ก๊อปต่อได้แม้ปิดหน้าจอหรือสลับไปใช้แอปอื่น (ทำงานเป็น foreground service พร้อม wake lock)
และมีตัวเลือก **Keep screen on** ให้หน้าจอไม่ดับระหว่างก๊อป

## ตัวเลือก

| ตัวเลือก | ความหมาย |
|---|---|
| Parallel copies | จำนวนไฟล์ที่ก๊อปพร้อมกัน ไฟล์เล็กจำนวนมาก: 8–16 · แฟลชไดรฟ์/SD card ช้า: 4–8 |
| Copy mode | **Merge**: ก๊อปไฟล์ใหม่และไฟล์ที่เปลี่ยน ไม่ลบอะไรที่ปลายทาง (ปลอดภัย เหมาะกับ backup) · **Mirror**: ทำให้ปลายทางเหมือนต้นทางทุกอย่าง ลบไฟล์ที่ไม่มีในต้นทาง (มีกล่องยืนยันก่อน) |
| Retries | จำนวนครั้งที่ลองใหม่เมื่อก๊อปไม่สำเร็จ |
| Exclude | ข้ามไฟล์/โฟลเดอร์ตามชื่อ คั่นด้วย `;` ใช้ `*` และ `?` ได้ เช่น `*.tmp; Thumbs.db` |

## วันที่ของไฟล์ (Keep original dates)

SAF เพียงอย่างเดียวตั้งวันที่แก้ไข (last modified) ของไฟล์ไม่ได้ ไฟล์ที่ก๊อปจึงจะได้วันที่เป็นวันที่ก๊อป
ซึ่งทำให้รูปที่ backup เรียงลำดับผิดในแอปจัดการไฟล์

ตัวเลือก **Keep original dates** (เปิดเป็นค่าเริ่มต้น ใน Settings) แก้ปัญหานี้:

- ต้องอนุญาต **"All files access"** (Android 11 ขึ้นไป) หรือสิทธิ์ที่เก็บข้อมูล (Android 10 ลงไป) ครั้งเดียว — แอปจะพาไปหน้าตั้งค่าให้
- หลังก๊อปแต่ละไฟล์ แอปจะตั้งวันที่ของไฟล์ปลายทางให้ตรงกับต้นฉบับ
- ไฟล์ที่ก๊อปไว้ก่อนหน้านี้ (ที่ได้วันที่ผิด) จะถูก **แก้วันที่ให้อัตโนมัติ** ในการ sync ครั้งถัดไป โดยไม่ต้องก๊อปใหม่
- ถ้าตั้งวันที่ไม่ได้ (เช่น บางเครื่องกับ SD card / USB) แอปจะบอกจำนวนไฟล์ที่ตั้งไม่ได้

## การตัดสินว่าไฟล์ "เหมือนเดิม"

แอปจะถือว่าไฟล์ **ไม่เปลี่ยน** เมื่อขนาดเท่ากันและไฟล์ต้นทางไม่ได้ใหม่กว่าไฟล์ปลายทาง
ไฟล์ที่เปลี่ยนจะถูกลบแล้วก๊อปใหม่

## หน้าจอระหว่างก๊อป

- **Copying now** — หลอด progress ตามจำนวน Parallel copies (ตั้ง 4 ก็มี 4 หลอด) แต่ละหลอดแสดงชื่อไฟล์ที่กำลังก๊อป, % และขนาด
  หลอดสีน้ำเงิน = ไฟล์ใหม่ · สีม่วง = อัปเดตไฟล์ที่เปลี่ยน · สีส้ม = กำลังลองใหม่ (retry)
- **Recent files** — รายการไฟล์ล่าสุดพร้อมป้ายสถานะ ✓ Copied · ↻ Updated · ⏭ Skipped · ✖ Failed · 🗑 Deleted
  กรองได้ด้วยปุ่ม All / Copied / Skipped / Problems และกด **Full log** เพื่อแชร์ log ทั้งหมด

## ทำไมถึงเร็ว

- อ่านรายชื่อไฟล์ทั้งโฟลเดอร์ด้วย query เดียว (ไม่ใช้ `DocumentFile.findFile()` ทีละไฟล์)
- เทียบไฟล์ต้นทาง/ปลายทางใน memory ครั้งเดียว
- ก๊อปหลายไฟล์พร้อมกันด้วย coroutines และ buffer 256 KB

## Signing (release key)

APK ทุกตัวเซ็นด้วย release key ส่วนตัว (`CN=NorthXbar`) ซึ่ง **ไม่ได้อยู่ใน repo**
GitHub Actions ดึงคีย์จาก repository secrets (Settings → Secrets and variables → Actions):

| Secret | ค่า |
|---|---|
| `RELEASE_KEYSTORE_BASE64` | ไฟล์ `.jks` ที่แปลงเป็น base64 |
| `RELEASE_KEYSTORE_PASSWORD` | รหัสผ่านของ keystore (คีย์ใช้รหัสเดียวกัน, alias `northxbar`) |

ถ้าไม่มี secrets ครบ การ build บน GitHub จะหยุดพร้อมแจ้ง error (ไม่มีการปล่อย APK ที่เซ็นด้วยคีย์อื่น)
**เก็บไฟล์ `.jks` และรหัสผ่านไว้ให้ดี** — ถ้าหาย จะอัปเดตทับแอปเดิมไม่ได้อีก

## Build เอง

เปิดโฟลเดอร์นี้ใน Android Studio แล้วกด Run หรือใช้คำสั่ง

```bash
./gradlew assembleRelease
```

ไฟล์ log ของแต่ละงานเก็บไว้ใน `Android/data/com.titipong.safmulticopy/files/logs/` และกด Share จากในแอปได้
